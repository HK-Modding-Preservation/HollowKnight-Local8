# Installing Hollow Knight 8-Player Co-op

Current public package: **v0.11.2**. Target game: **Hollow Knight 1.5.78.11833** with the matching Modding API.

## Manual installation

1. Install the matching Hollow Knight Modding API.
2. Download [HollowKnightLocal8-v0.11.2.zip](https://github.com/RaulSB-code/HollowKnight-Local8/releases/download/v0.11.2/HollowKnightLocal8-v0.11.2.zip).
3. Close the game. Extract the ZIP into `Mods/Hollow Knight 8-Player Co-op/`, so that the installed file is `Mods/Hollow Knight 8-Player Co-op/HollowKnightLocal8.dll`.
4. Replace the previous DLL. Remove duplicate copies from other mod folders.
5. Start the game. The mod list must show **Hollow Knight 8-Player Co-op 0.11.2**.
6. Connect controllers before loading a save. P1 automatically uses the active or first connected controller; Start on other controllers adds P2–P8.
7. To use keyboard P1, open **F8 → Players & controls → Keyboard**. To choose another controller for P1, use **Assign P1** beside it.

There are no additional installation assets: artwork and translations are embedded. Existing technical filenames, settings and save identifiers are retained.

## Lumafly

Once the ModLinks entry is accepted and updated, search for **Hollow Knight 8-Player Co-op** and install/update it through Lumafly. The ModLinks version is **0.11.2.0**.

## Optional companion mods

- **Custom Knight**: individual skins and easier player identification.
- **Enemy HP Bar**: readable shared enemy/boss health.

Neither is required. See [compatibility](COMPATIBILITY.md) before using large content mods.
