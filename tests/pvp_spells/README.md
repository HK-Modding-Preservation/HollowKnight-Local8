# Spell-only duel checks

Run `python3 tests/pvp_spells/run.py --dotnet /path/to/dotnet`.

Execute the production spell-duel service, settings normalization, arena options, input pump and SOUL commit path against controlled native-data/action doubles. Cover eight independent recipients, fractional rates and capacity limits, pauses/F8/loading/intermission, death/roster/round/exit cleanup, rule snapshots, native menu ownership, other offensive kinds and SPELL-typed charm sources, normal/friendly-fire isolation, and live-copy arena casting safeguards. Existing match/arena code owns restoration of the original adventure resources.

These tests do not load Unity physics, PlayMaker spell animations, detours or physical controllers. In-game spell collision/rendering still needs gameplay verification.
